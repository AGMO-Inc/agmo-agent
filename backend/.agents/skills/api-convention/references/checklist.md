## 1.17. 적용 체크리스트

### 1.17.1. 신규 API 작성 체크리스트

- [ ] URL이 `/api/v1`로 시작한다 (`1.4.6`)
- [ ] URL이 복수형 명사 + kebab-case + 소문자 규칙을 따른다 (`1.4.1`)
- [ ] 중첩 깊이가 2단계를 넘지 않으며, 필요 시 평면화를 검토했다 (`1.4.2`, `1.4.3`)
- [ ] 관리자 API는 `/api/v1/admin` 접두사를 사용했다 (`1.4.5`)
- [ ] 메서드/상태코드 선택이 규칙에 맞다 (`1.5.1`, `1.6.1`)
- [ ] 생성 API는 `201 + Location`을 반환한다 (`1.6.2`)
- [ ] 비동기 API는 `202 + operationId + Location(/api/v1/operations/{operationId})` 패턴을 따른다 (`1.6.4`)
- [ ] 성공 응답에서 HTTP status와 `ApiResponseFormat.status`가 일치한다 (`1.6.1`, `1.9.1`)
- [ ] 비페이징 응답은 `pageInfo`를 포함하지 않는다 (`1.9.1`, `1.9.2`)
- [ ] DTO가 API/Service 계층으로 분리되어 있다 (`1.1.2`, `1.2.1`, `1.11.1`, `1.11.2`)
- [ ] `@RequestBody`에는 `@Valid`를 적용했다 (`1.3.1`, `1.16.1`)
- [ ] `@PathVariable`, `@RequestParam`에도 필요한 Validation을 적용했다 (`1.16.5`)
- [ ] Boolean 필드명에 `is/can` 접두어를 사용하지 않았다 (`1.9.3`)
- [ ] 금액은 `BigDecimal + scale=2 + HALF_UP + ISO-4217` 규칙을 따른다 (`1.15.3`)

### 1.17.2. 예외/에러 처리 체크리스트

- [ ] 실패 응답이 `1.10` 외부 계약을 따른다 (`1.10.1`)
- [ ] Validation 실패 시 `data`에 오류 필드명 문자열 배열을 반환한다 (`1.10.1`, `1.16.7`)
- [ ] Controller 단에서 예외를 직접 응답하지 않고 `@RestControllerAdvice`로 처리한다 (`1.10.2`)
- [ ] 예외 매핑은 `1.10.3` 표 기준으로 처리한다 (`1.10.3`)
- [ ] 업스트림 연동 예외는 `502 Bad Gateway`로 매핑한다 (`1.10.3`, `1.6.5`)
- [ ] 미처리 예외(`500`) 발생 시 Alert를 발송한다 (`1.10.2`, `1.10.3`, `1.13.3`)

### 1.17.3. PR 리뷰 체크리스트

- [ ] Swagger 문서가 최신 응답/에러 규칙과 일치한다 (`1.2.1`, `1.6`, `1.10`)
- [ ] 신규 API가 기존 클라이언트 호환성 원칙을 위반하지 않는다 (`1.1` 주석)
- [ ] 버전/폐기 정책(Deprecation, Sunset, 90일 공지)을 준수한다 (`1.4.7`)
- [ ] 브레이킹 변경 여부를 점검하고 완화 조건/마이그레이션 계획을 기록했다 (`1.4.8`)
