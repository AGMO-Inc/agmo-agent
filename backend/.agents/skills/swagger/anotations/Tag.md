# `@Tag`

## 목적

API를 도메인 단위로 묶어 문서 목차를 만든다.

## 규칙

- 컨트롤러 클래스(또는 ApiDocs 인터페이스)에 `@Tag`는 정확히 1개만 사용한다.
- `Tag.name`은 “번호 + 도메인명” 형식을 권장한다.
  - 번호는 00부터 99까지 지정할 수 있다.
  - 같은 도메인은 00-0 형식으로 지정한다.
  - 예시: `"04-1. 앱 생성"`, `"04-2. 앱 리뷰"`, `"05-1. 회원 관리"`
- `Tag.description`은 해당 도메인의 기능 범위를 1~2문장으로 요약한다.

## 예제

```kotlin
@Tag(
  name = "03-1. 사용자 - 회원 관리",
  description = "회원(User) 정보 생성/수정/조회/삭제 등 회원 관련 API"
)
interface UserApiDocs {
  // ...
}
```
